# EduGenie

## Google Gemini Powered Learning Assistant

EduGenie is a student-focused AI learning assistant built with:

- Python
- FastAPI
- Jinja2
- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini API

## Features

### 1. AI Chat

Students can ask academic questions and receive AI-generated explanations.

### 2. Topic Explanation

Explain difficult concepts using:

- Simple definition
- Key points
- Real-life analogy
- Example
- Revision point

### 3. Quiz Generator

Generate AI-powered MCQ questions.

Available difficulty levels:

- Easy
- Medium
- Hard

### 4. Smart Summary

Students can paste study notes and receive:

- Overview
- Key points
- Important terms
- Exam revision points
- Flashcards

### 5. PDF Summary

Upload a selectable-text PDF and generate a summary.

### 6. Personalized Learning Path

Create a learning roadmap based on:

- Goal
- Student level
- Number of weeks

### 7. Study History

AI activities are stored in SQLite.

## Requirements

- Windows 10/11
- Python 3.10+
- VS Code
- Internet connection
- Gemini API key
